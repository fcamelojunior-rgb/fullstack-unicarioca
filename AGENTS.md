# Orientações para o agente de IA

## Objetivo

Manter o laboratório Full Stack simples, funcional e fácil de compreender por alunos iniciantes.

## Regras de desenvolvimento

- Priorize clareza, simplicidade e organização.
- Preserve a estrutura atual do projeto sempre que possível.
- Evite adicionar bibliotecas sem necessidade.
- Explique a proposta antes de realizar mudanças significativas.
- Não altere configurações ou dados persistentes sem explicar o impacto.
- Nunca invente senhas, tokens ou outras informações secretas.
- Mantenha a comunicação entre frontend e backend funcionando.
- Considere o banco SQLite e o volume Docker ao propor alterações.

## Validação

- Verifique a sintaxe dos arquivos modificados.
- Teste os endpoints da API quando houver mudanças no backend.
- Confira o carregamento dos projetos no frontend.
- Informe quais arquivos foram alterados e quais testes foram realizados.
